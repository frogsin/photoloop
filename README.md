# PhotoLoop · 环绕建模

> 绕物体拍一圈照片，自动生成可用的三维模型——**并且告诉你哪里拍错了。**

PhotoLoop 不是一个重建引擎，而是在 COLMAP 之上补齐它缺的两块：

1. **事前诊断**：在跑重建之前，从数据库判断这组照片有没有希望
2. **事后修整**：把稀疏点云变成能直接用于 Poisson 重建的干净点云

---

## 为什么需要它

用 COLMAP 做三维重建，实际遇到的困难几乎都不在「算法」上：

| 问题 | COLMAP 的表现 | PhotoLoop 的做法 |
|---|---|---|
| 图片混入了不同来源、分辨率不一致 | 静默建出多个相机，光束平差不稳定 | `scan check` 直接检出并点名可疑图片 |
| 照片太少 / 重叠不足 | 重建「成功」但只有几千个点 | `scan check` 用验证通过率提前预警 |
| 点云含离群点 | Poisson 生成巨型壳，主体被淹没 | `scan cloud` 按轨迹长度与误差清洗 |
| 法向方向不一致 | 网格碎成一团气泡，原因毫无提示 | `scan cloud` 用观测相机定向法向 |
| 重建失败 | 崩溃，退出码 `0xC0000409` | — |

其中**法向定向**是效果最显著的一步：实测中 **69.7%** 的 PCA 法向是反向的，校正前后网格的可用性天壤之别。

## 安装

只需要 Python 3.9+ 与 numpy：

```bash
pip install -r requirements.txt
```

或直接把 `scan/` 目录放进你的工程。

## 使用

### 1. 体检数据库（重建之前）

```bash
python -m scan check D:\recon\ob01\database.db
```

输出示例：

```
【图像与相机】
  图像数量                                      39
  相机数量                                       5

  单独成相机的图像（4 张）：
    - IMG_20261103_122108.jpg   (相机 2)
    - IMG_20261103_122131_1.jpg   (相机 3)
    ...

[WARN] 检测到 5 个相机（理想应为 1 个）。通常是混入了不同分辨率的图片，或部分图片缺少 EXIF。
```

### 2. 分析模型质量

```bash
python -m scan report D:\recon\ob01\sparse\0
```

输出重投影误差、轨迹长度、视差比、方位角覆盖等指标，并给出可执行的告警。

### 3. 生成可直接重建的点云

```bash
python -m scan cloud D:\recon\ob01\sparse\0 -o cloud.ply
```

```
【结果】
  原始点数                                118,125
  保留点数                                 52,553
  翻转法向                        36,638  (69.7%)
```

得到的 `cloud.ply` 带有已校正的法向，在 MeshLab 中**直接**运行
`Screened Poisson Surface Reconstruction` 即可。

> ⚠ 不要在 MeshLab 里再点「Compute normals for point sets」——那会用 PCA 重算，
> 把已校正的方向覆盖掉。

## 参数

`scan cloud` 的默认值来自实测调优：

| 参数 | 默认 | 含义 |
|---|---|---|
| `--min-track` | 4 | 点的最小轨迹长度（被多少张图观测到） |
| `--max-error` | 1.5 | 最大重投影误差（像素） |
| `--keep` | 85 | 按到点云中心距离保留的百分比 |
| `--knn` | 32 | 法向估计的邻域大小 |
| `--no-normals` | — | 跳过法向估计 |

同一物体、同一部手机，三组受控实验：

## 目录

```
scan/
  colmap_io.py   COLMAP 稀疏模型（BIN）读取，零外部依赖
  dbcheck.py     database.db 体检与诊断规则
  cloud.py       点云清洗 + 法向估计 + 相机定向
  report.py      模型质量指标
  ply_io.py      PLY 读写
  cli.py         命令行入口
```

## 已知限制

- **不做重建与稠密化**，这些交给 COLMAP 与 MeshLab。
- 法向定向假设相机在物体外侧环绕；室内外翻的内景扫描不适用。
- 方位角覆盖基于相机分布的最佳拟合平面，相机高度变化很大时会失真（报告中会给出共面性指标）。
- 依赖 COLMAP 的目录结构与数据库表结构（已在 COLMAP 4.2.1 上验证）。
